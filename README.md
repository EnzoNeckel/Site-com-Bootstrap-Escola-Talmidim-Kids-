# Site-com-Bootstrap-Escola-Talmidim-Kids-
# Projeto Web com Bootstrap 5

Projeto desenvolvido para a atividade AP2 da disciplina de Desenvolvimento Web do curso de Análise e Desenvolvimento de Sistemas da ULBRA – Campus Torres.

---

## Sobre o Projeto

O projeto consiste em um website responsivo desenvolvido utilizando o framework Bootstrap 5, com foco em organização visual, responsividade e utilização de componentes modernos do framework.

O tema escolhido foi livre, permitindo explorar diferentes recursos de layout e componentes interativos do Bootstrap.

---

## Tecnologias Utilizadas

* HTML5
* CSS3
* Bootstrap 5
* Flexbox
* GitHub Pages

---

## Funcionalidades

* Layout responsivo para:

  * Mobile
  * Tablet
  * Desktop

* Barra de navegação responsiva (Navbar)

* Menu suspenso (Dropdown)

* Carousel com múltiplas imagens

* Modal interativo

* Estrutura semântica HTML5

* Organização de layout utilizando Grid System e Flexbox

* Navegação entre múltiplas páginas

## Responsividade

O site foi desenvolvido utilizando o sistema de Grid do Bootstrap 5 e Media Queries implícitas do framework, garantindo adaptação para diferentes tamanhos de tela.

---

## Utilização do Flexbox

Foi utilizado Flexbox para alinhamento e distribuição de elementos em determinadas seções do layout, proporcionando maior flexibilidade e organização visual.

Exemplo:

css
display: flex;
justify-content: center;
gap: 20px;
```
